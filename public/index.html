Test Case Format

Fixed

Follows the user-story-test-case-generator skill: an analysis, then these columns with one row per step.

  1. Test Case ID
  2. Title
  3. Module / Feature
  4. Preconditions
  5. Tags
  6. Steps
  7. Results
  8. Type of Test Case
  9. Priority (kept)
  10. Estimate
  11. Owner
  12. Automation Status
  13. State

Bug Report Format

Fixed

Follows the bug-report-generator skill: these sections and nothing else.

  1. Title
  2. Link
  3. Environment
  4. Steps to Reproduce
  5. Actual Result
  6. Expected Result
  7. API Evidence (backend bugs only)
  8. Severity
  9. Priority
