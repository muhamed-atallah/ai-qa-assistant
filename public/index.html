Step 3: Configure Generation

Customize how your test cases are generated (optional)

Test Case Format

Fixed

Follows the user-story-test-case-generator skill: an analysis, then these columns with one row per step.

  1. Test Case ID
  2. Title
  3. Module / Feature
  4. Preconditions
  5. Tags
  6. Steps
  7. Results
  8. Type of Test Case
  9. Priority (kept)
  10. Estimate
  11. Owner
  12. Automation Status
  13. State

Checklist Format

Fixed

One check per rule in the story, each traced to the story lines it verifies. Lines with no check are flagged so none is missed.

  1. Check ID
  2. Section
  3. Check
  4. Expected Result
  5. Story Lines
  6. Priority
  7. Status (Pass / Fail, marked by you)
  8. Notes

Bug Report Format

Fixed

Follows the bug-report-generator skill: these sections and nothing else.

  1. Title
  2. Link
  3. Environment
  4. Steps to Reproduce
  5. Actual Result
  6. Expected Result
  7. API Evidence (backend bugs only)
  8. Severity
  9. Priority
